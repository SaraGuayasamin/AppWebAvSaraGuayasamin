# 2026-10-17 Work Log

## PoliMusic ASP Classic - Complete Application Built

Created full ASP Classic web application for university assignment (Aplicaciones Web Avanzadas):

### Files created:
1. `includes/conexion.asp` - ADO connection functions (AbrirConexion/CerrarConexion), MSOLEDBSQL provider
2. `includes/seguridad.asp` - Session validation (RequerirSesion, EsAdmin, RequerirAdmin)
3. `login.asp` - Login form with parameterized query against TBL_USER
4. `songs.asp` - Main page: song list table, HTML5 audio player, role-based CRUD
5. `song_save.asp` - INSERT/UPDATE with parameters, admin-only validation
6. `song_delete.asp` - DELETE with parameters, admin-only validation
7. `play_count.asp` - Increment PLAYS via fetch, returns JSON
8. `logout.asp` - Session.Abandon
9. `index.asp` - Router to login/songs
10. `css/site.css` - "Sunset Vinyl" palette, responsive, cards, shadows
11. `js/app.js` - Audio player, fetch, toggle, confirm delete
12. `web.config` - IIS error config (NOT ASP.NET config)
13. `database/setup.sql` - SQL script to create tables and seed data
14. `SETUP.md` - Complete IIS configuration guide
15. `songFiles/*.mp3` - 5 placeholder MP3 files for testing

### Key design decisions:
- Doble validation: hide buttons in HTML (client) + RequerirAdmin() in server for CRUD
- FileSystemObject reads /songFiles for the admin's create/edit dropdown
- SONG_PATH uses "~/songFiles/..." in DB, Replace("~/","") when rendering
- web.config is for IIS settings only (error display, default doc), not ASP.NET
